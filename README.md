# Srehari Saravanan — Security Engineering Portfolio

A responsive, dark-mode portfolio for Srehari Saravanan, Security Engineer III.

## Included files

- `index.html` — portfolio content and search-engine metadata.
- `styles.css` — responsive design, dark theme, and motion preferences.
- `script.js` — navigation, header, and progressive scroll interactions.
- `favicon.svg` — branded portfolio icon.

## Run locally

Serve the repository with any static web server:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish with GitHub Pages

In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, select the **main** branch and the **/ (root)** folder, and save. The portfolio will be available at `https://sreharisaravanan.github.io/srehariportfolio/` after GitHub Pages completes its deployment.
